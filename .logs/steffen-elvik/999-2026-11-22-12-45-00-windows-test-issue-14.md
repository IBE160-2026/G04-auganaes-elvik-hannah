### Plan

- Kjøre `uv run pytest` og `npm test -- --run`, deretter oppskriftene «Prøv porteføljen», «Prøv å slette konto» og «Prøv å legge til og fjerne oppgaver» med Claude in Chrome.
- Fullføre det som manglet: Postgres-testene, Anders som leietaker (403) og porteføljen ved 320 og 700 px.
- Én issue, branch og PR per rettelse (CLAUDE.md).
